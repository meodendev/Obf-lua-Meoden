# 🚀 Lua/Luau Obfuscator for Roblox

Professional web-based obfuscator for Roblox Lua scripts with AST-based transformations.

## ✨ Features

### Obfuscation Techniques
- ✅ Variable & Function Renaming
- ✅ String & Number Encryption
- ✅ Control Flow Flattening
- ✅ Junk Code Injection
- ✅ Dead Code Removal
- ✅ VM-level Obfuscation (Extreme)
- ✅ Anti-Debug & Anti-Dump Protection

### Roblox-Specific
- ✅ Full Luau Support
- ✅ Preserves Roblox APIs
- ✅ ModuleScript & LocalScript Support
- ✅ Type Annotations Support

### Interface
- 🎨 Dark Theme
- 📝 Monaco Editor with Syntax Highlighting
- 📊 Real-time Statistics
- 🔄 Drag & Drop Support
- 📜 History Tracking

## 🛠️ Tech Stack

### Frontend
- React 18 + Vite
- Monaco Editor
- Tailwind CSS
- React Dropzone

### Backend
- Node.js + Express
- Lua AST Parser
- JWT Authentication
- Rate Limiting
